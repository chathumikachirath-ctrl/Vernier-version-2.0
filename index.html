How to Use

  1. Drag the metallic object close to the jaws/depth gauge.
  2. The movable jaw automatically locks tightly onto the object.
  3. Read the Main Scale line immediately before the Vernier Zero mark.
  4. Identify the Vernier line that directly aligns with a Main Scale line (highlighted in red).
  5. Calculate: Final = MSR + (VC × LC)

Physics Theory Guide

Vernier Caliper: A precision instrument used to measure internal, external, and depth dimensions accurately.

Least Count (LC): The smallest value that can be measured accurately. Computed as:
LC = 1 Main Scale Div - 1 Vernier Scale Div

Main Scale Reading (MSR): The last main scale division before the Vernier zero line.

Vernier Coincidence (VC): The specific division mark on the movable Vernier scale that perfectly aligns with any mark on the main scale.
